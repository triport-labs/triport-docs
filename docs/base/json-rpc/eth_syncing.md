# eth_syncing

> Return node sync progress or false.

## Purpose and interpretation

The response is either false or a synchronization-status object under the schema. False is a boolean observation, not the string false and not a block height. When an object is present, interpret its progress fields as quantities before calculating a difference. This call helps diagnose node synchronization, but it is not a general health check: an apparently synchronized node can still lack optional methods, historical state or a particular transport. Combine it with the checks relevant to the application.
