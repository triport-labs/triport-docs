# eth_getBlockTransactionCountByNumber

> Return the transaction count in a block.

## Purpose and interpretation

This lookup returns a transaction count for the selected block height or tag without downloading the block body. Decode the hexadecimal quantity before displaying it or using it as an array bound. The count applies to transactions in that block, not to an account's nonce or lifetime activity. If the selector can move, such as latest, a later block-by-index lookup may resolve a different block; pin a height and verify its hash for consistent processing.
